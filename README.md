# 📰 Gridnews:  Express.js + EJS Blog Site

A dynamic blog/news website built with **Express.js** and **EJS templating**, designed to display news content in a clean layout and support easy content management via an **admin upload page**.

🌐 [Live Demo](https://gridnews.onrender.com/) 

---

## ✨ Features

- 📝 **Admin Page**: Secure section for uploading and managing blog/news content
- 📄 **Dynamic Rendering**: Articles are rendered dynamically using EJS
- 🗃️ **Category-Based Filtering** (optional if implemented)
- 📅 **Date & Time Stamps** for articles
- 🔍 **Clean, responsive UI** for better readability across devices
- 🧠 **SEO-friendly pages** using dynamic meta tags (if applicable)

---

## 🛠️ Tech Stack

- **Backend**: Express.js (Node.js)
- **Templating**: EJS
- **Database**: MongoDB 
- **Authentication**: (e.g., session-based login for admin) 
- **Styling**: CSS
